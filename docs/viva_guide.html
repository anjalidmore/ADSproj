Viva study guide · Applied Data Science

Global CO₂ Emissions Analytics

We took every concept from ADS Modules 1–6 and applied it to a real dataset of 50,411 country-year rows instead of 10-row classroom tables. A Python package does the maths with the course’s own formulas. A test suite proves each formula reproduces the lecture examples. A Streamlit dashboard, a report and a slide deck all read their numbers from the same code.

50,411 × 79rows × columns, 1750–2024
219countries among 254 entities
53syllabus concepts implemented
56automated tests, all passing

Three-sentence answer to “what did you do?” We cleaned the Our World in Data CO₂ dataset so that countries and regional totals are never mixed, then described, compared, tested and modelled national emissions with methods from every module. The headline results: world emissions hit a record 38.6 Gt in 2024; per-person emissions are extremely skewed (mean 4.63 t vs median 3.21 t); continents differ significantly; and across countries, income is linked to emissions mainly through energy use. Every result is checked against the course worked examples and against standard libraries.

Run it

The project uses uv, which installs Python 3.12 and the exact library versions in uv.lock.

uv sync                                  # install
uv run pytest                            # 56 tests
uv run python scripts/export_results.py  # results.json, figures, concept matrix
uv run streamlit run app/Home.py         # dashboard on http://localhost:8501

The report is rebuilt with scripts/build_report.py (needs pandoc). If the raw file is ever replaced, its SHA-256 hash will no longer match data/raw/MANIFEST.json and the Dataset Explorer page says so.

How the code fits together

The design rule: every number is computed, nothing is typed in. Analysis code knows nothing about Streamlit, and the app contains no statistics of its own; it calls the package.

data/raw/OWID CSV, codebook, continent lookup, hashes
→
data.pytag countries vs aggregates, add continent, flags
→
descriptive · correlation · inference · regression · lof · timeseriesone module per syllabus unit
→
results.pyapplies them to the real data
→
app/ · results.json · report · slidesall read the same numbers

Three data layers are kept apart: raw (never edited), clean (every raw row plus entity_type, continent, gdp_per_capita and flag columns), and analysis-ready (country-only slices built per analysis by cross_section(), world_series() and paired_years()).

Data decisions you must be able to defend

DecisionWhy
Keep every raw row; tag entity_type36 entities have no ISO code: continents, income groups, a duplicate “(GCP)” set of regions, EU, international aviation and shipping, Kuwaiti oil fires, Ryukyu Islands. Adding them to countries double-counts. Only Kosovo is a real country without an ISO code.
Check World = Σ countries + aviation + shippingProves the classification. 2024: 37,406 + 569 + 623 ≈ 38,599 Mt; the residual is under 0.5% in every test year.
No imputation; listwise deletion per analysis onlyA blank means “not reported”, never zero emissions. Each result states its own n (214 countries for per-person CO₂ in 2024, 164 for the GDP models).
Flag outliers, don’t delete themQatar at 41.3 t per person is real, not an error. We use medians, IQR and log scales so a few extremes don’t dominate.
2024 for emissions, 2022 for anything with GDPThe GDP series ends in 2022; energy starts in 1965; consumption-based CO₂ starts in 1990 (about 120 countries).
log₁₀ for tests and regressionRaw per-person CO₂ has β₂ = 14.1; the log has β₂ = 2.82 (normal = 3) and follows the 68–95–99.7 rule.
Zero-CO₂ rows kept640 country-years have CO₂ = 0; 578 are before 1950 (years before records begin). The recent ones are Antarctica and tiny territories.
Continent lookup addedThe CO₂ file has no country → continent column, and ANOVA and two-sample tests need groups. We used OWID’s own lookup; only Antarctica has no continent.

Module by module

For each module: what we did, where it lives, and the number to quote.

M1Data science process

  • CRISP-DM shapes the project: questions → preparation → modelling → evaluation → dashboard → findings.
  • Cleaning: duplicates (0), inconsistent entities (aggregates tagged), missing values (not imputed), invalid values (none in non-negative columns), outliers (flagged).
  • Hold-out 2/3 : 1/3 on the multiple regression: test R² = 0.938 (109 train, 55 test).
  • 5-fold cross-validation: mean R² 0.946 (multiple), 0.803 (simple). Close to training values, so no overfitting.
  • Bootstrapping: 95% CI for the median CO₂ per person = 2.54 – 3.73 t (5,000 resamples).
  • Normalisation: min–max before LOF so neither axis dominates the distance.

Classification & tabulation (page: Classification & Diagrams)

  • Geographical: by continent. Asia’s 50 countries emit 60.6% of world CO₂; North America 9.99 t per person vs Africa 0.99 t.
  • Chronological: world CO₂ by decade, 7.3 Gt a year in the 1950s → 37.2 Gt in 2020–2024. Growth per decade fell from about 54% (1970s) to 5%.
  • Qualitative: two-fold (62 countries fell since 2005, 152 rose or same); manifold = continent → fell/rose → largest fuel source (oil in 159 countries, coal in 32).
  • Quantitative: 5 magnitude classes of CO₂ per person (<1, 1–3, 3–6, 6–10, 10+ t).
  • Tables: simple (one-way), two-way (continent × class, with totals), higher-order (continent × fell/rose × class).

More univariate methods (Descriptive Statistics page)

  • Discrete series: years with falling CO₂, 2006–2024, n = 214. Mean ΣfX/N = 7.17 (short-cut gives the same), median 7, mode 6, Q1 5, Q3 10, σ 3.37 (actual and assumed-mean methods agree). Median and quartiles are read from the cf column with no interpolation.
  • Inclusive → exclusive: 0–3, 4–7, … become −0.5–3.5, 3.5–7.5, …; grouped median 6.65.
  • Ogives: less-than and more-than curves cross at N/2 = 107 → median 3.1607, the same as the formula L + (N/2 − cf)/f × i.
  • Open-end class “15 t and above”: mean 4.598 (assumed width) vs 4.907 (all closed) vs 4.632 exact. The median 3.161 does not change.
  • Correcting wrong items: averaging the 17 aggregate rows with countries gives 4.698; the correction formula recovers 4.632.
  • Moments: μ₂ 30.26, μ₃ 462.4, μ₄ 12,918; β₁ 7.72, β₂ 14.11. Empirical mode 3Med − 2Mean = 0.36 vs grouped mode 2.05: the relation fails for extreme skew.

Types of correlation

  • Positive: log GDP vs log CO₂ pc, r = 0.907. Negative: log GDP vs log CO₂ per kWh, r = −0.461 (richer countries, cleaner energy); UK CO₂ vs year, r = −0.931. None: population vs CO₂ pc, r = −0.002. Non-linear: raw GDP vs CO₂ pc, r = 0.745.
  • Partial: r(CO₂, GDP | energy) = −0.151, r(CO₂, energy | GDP) = 0.850. Multiple R = 0.975 = √(regression R² 0.951).

Diagrams and graphs: simple, multiple, sub-divided, percentage, deviation and broken bars; rectangle (width = population, height = per person, area = total), square (side = √value), circle (r = √(value/π)), pie, pictogram, cartogram (world map); line graph with and without a false baseline; histogram, frequency polygon, ogive, box plot, distribution chart, scatter, scatter matrix, bubble chart.

M3Inferential statistics

  • Normal / empirical rule: raw values within ±1σ: 88.8% (normal 68.3%). Log values: 70.1 / 93.9 / 100% vs 68.3 / 95.4 / 99.7%.
  • CLT: 10,000 samples of n = 30 from the real data. The SD of the sample means is 1.018, against σ/√n = 1.004. Skewness falls from 0.78 to 0.30.
  • CI: 95% z-interval for the mean = 3.89 – 5.37 t.
  • z-test: H₀ μ = world per-person 4.729. Z = −0.26, fail to reject.
  • Paired t (2005 vs 2024, n = 214): 5.28 → 4.63 t, t = −2.86, p = 0.0046, reject H₀. Yet 127 countries rose and 87 fell.
  • Independent t (log, Europe 44 vs Asia 50): t = 1.75, p = 0.083, fail to reject. Variance ratio 9.3, so we also report Welch’s test: p = 0.070.
  • One-way ANOVA (log, 6 continents): F = 30.87 vs critical 2.26, p ≈ 2 × 10⁻²³, η² = 0.43.
  • Two-way ANOVA without replication (continent × 5 years): continent F = 60.1 (significant), year F = 1.36 (not significant).
  • Type I/II: simulated Type I rate 0.09 at n = 40 (nominal 0.05). β = 0.51 for a 1.5 t shift (power 0.49).
  • Poisson: yearly count of countries with a >10% fall has mean 11.97 and variance 65.4. Dispersion 5.5, so not Poisson.

M4Regression

  • Simple: log CO₂pc = 1.0447 · log GDPpc − 3.8696. R² = 0.823, t(slope) = 27.4. The slope is an elasticity: 1% richer goes with about 1.04% more CO₂ per person.
  • Multiple (+ log energy per person): Ŷ = −3.169 − 0.117·X₁ + 0.986·X₂. R² 0.951, adjusted R² 0.950, F = 1554 (critical 3.05).
  • t-tests: energy t = 20.5 (significant); GDP t = −1.94, p = 0.054 (not significant). Cause: multicollinearity, r₁₂ = 0.94.
  • Errors: MAE and RMSE on the log scale. MAPE is computed after converting back to tonnes (23.7% multiple, 49.0% simple), because log values near 0 make MAPE explode.

M5Local Outlier Factor

reach(p,o) = max(k-dist(o), d(p,o)) · lrd(p) = |Nₖ(p)| / Σ reach · LOF(p) = mean lrd(Nₖ(p)) / lrd(p)

  • Manhattan distance on min–max scaled log GDP and log CO₂ per person, k = 10, 164 countries (2022).
  • Top: Qatar 2.37, North Korea 1.86, Norway 1.67, Switzerland 1.59, Venezuela 1.59, Burundi 1.58. 6 countries are above 1.5.
  • Only Qatar and Trinidad & Tobago are in both the LOF top 10 and the IQR list. LOF is two-dimensional and local, so it also finds low emitters for their income.

M6Time series

  • Decomposition needs seasons inside a year, and OWID data is annual. It is implemented and reproduces the slide example exactly (indices −10.4375, −11.6875, 6.0625, 16.0625; forecasts 23.31 and 43.56). On CO₂ we use only its trend step, a centred 5-year moving average.
  • Hold-out: train 1950–2019, test 2020–2024. MAPE / MASE: naïve 2.93% / 2.08, MA(3) 3.13% / 2.25, linear trend 2000–2019 7.57% / 5.43, average 43.7% / 31.5.
  • All MASE > 1: nothing beat “same as last year”. The trend overshoots because growth slowed after 2013 and then COVID hit.

Course conventions, and four errors we found

  • Quartiles use the k(N+1)/4 position with interpolation between neighbours, which equals NumPy’s “weibull” method. pandas and Excel use other conventions, so their Q1 differs (1.014 vs our 0.985).
  • σ divides by N on the formula sheet; the t-test slides use s with n − 1. We report both.
  • Classes ≈ √n for histograms: √214 ≈ 15, rounded to a width of 3 t, giving 14 classes.
Errors in the course material. (1) The formula sheet’s kurtosis table pairs the shape descriptions with the wrong β₂ values; β₂ > 3 means more peaked with heavier tails. (2) The ANOVA slides compute the grand mean as the mean of sample means, which is only correct for equal group sizes. Our continents have 12–55 countries, so we use the mean of all observations (0.357 vs 0.404), and SS_T = SS_B + SS_W then holds exactly. (3) Module 4’s slide testing b₂ reuses b₁’s numbers. (4) Module 2’s “median from cumulative data” example uses i = 10 for classes that are 5 wide and prints 14.29; the correct median is 10 + (327.5 − 224)/241 × 5 = 12.15.

How we know the numbers are right

  • Lecture examples (tests/test_course_examples.py): Module 2 discrete mean (41), discrete median (₹16,800), discrete quartiles (P20 = Q1 = D3 = 20, Q3 = 40), grouped Q1 (10), corrected means (39.7, 40.18), open-end mean; IQ one-sample t (t = −0.62, CI 87.0–107.4), diet independent t (0.609), soldiers paired t (2.16), wait-time CI (42.23–47.77), ocean z (2.067), wheat ANOVA (F = 1.5), multiple regression (b₁ 3.1479, b₂ −1.6561, R² 0.9626), expenditure regression (8.4, 3.2), 4-point LOF (d = 2.0), both decompositions, average and MA forecast errors, Poisson hospital example.
  • Independent libraries (tests/test_cross_checks.py): quantiles vs NumPy, kurtosis and t-tests vs SciPy, two-way ANOVA and regression standard errors vs statsmodels, LOF vs scikit-learn.
  • Data (tests/test_data.py): hash, shape, unique key, nothing imputed, Kosovo is a country, World reconciliation.
  • App (tests/test_app.py): all 9 pages render; edge cases (empty filters, years without GDP) were also exercised.
  • One source of numbers: dashboard, report, slides and this guide all come from results.py.

The only mismatch with a slide is the diet example: t = 0.6103 exactly, against 0.609 on the slide, because the slide rounds √10.74 before dividing.

Limitations to state before you are asked

  • The ~214 countries are almost the whole population, not a random sample. Read p-values and CIs as statements about the process that generates emissions (a super-population view).
  • All relationships are cross-country associations. Energy and CO₂ are partly the same quantity, so R² = 0.95 is partly built in.
  • Assumptions are only approximately met: normality holds on the log scale only; continent variances differ (hence Welch); predictors are collinear.
  • Only fossil and industry CO₂ (territorial). Land use, methane and consumption-based emissions are outside the main analysis.
  • Coverage is uneven: about 5 countries in 1750, about 175 in 1950, 216 from 2000.
  • The forecast hold-out is 5 years and contains the 2020 shock. Annual data has no seasonality.
  • OWID revises its data; our numbers refer to the hashed 30 Sep 2026 revision.
